## 3. The paper skeleton (what a class-3 science paper actually looks like)

Class 3 has no public board exam; each school sets its own paper. The recurring
skeleton across schools, guide books and Satt's written section is:

| # | Section | Typical marks | Item count |
|---|---|---|---|
| ১ | সঠিক উত্তরে টিক (MCQ) | ১০ | ১০ |
| ২ | শূন্যস্থান পূরণ (শব্দবাক্স সহ/ছাড়া) | ১০ | ৫–১০ |
| ৩ | শুদ্ধ/অশুদ্ধ নির্ণয় | ৫–১০ | ৫–১০ |
| ৪ | বাম-ডান মিলকরণ | ৫–১০ | ৪–৫ জোড়া |
| ৫ | সংক্ষিপ্ত উত্তর | ২০ | ৫–১০ |
| ৬ | বর্ণনামূলক উত্তর | ২০ | ২–৫ |
| **Total** | | **৭০** (লিখিত) | |

Marks are not standardised — the same six sections appear as 50, 70 or 100-mark
papers. The app should therefore treat the section list as fixed and the marks/counts
as teacher-controlled, exactly like the existing per-type count boxes.

## 4. Complete pattern catalogue

### 4.1 বহুনির্বাচনী (MCQ) — ৪টি অপশন, ১টি সঠিক

The Satt filter exposes these MCQ sub-types: **গাণিতিক, চিত্রযুক্ত, উদ্দীপক, ব্যাখ্যাসহ**.
In practice the class-3 science items fall into these archetypes:

| Archetype | Stem shape | Example idea (own wording) |
|---|---|---|
| সরাসরি জ্ঞান | “নিচের কোনটি …?” | কোনটি মূলের কাজ? |
| সংজ্ঞা চেনা | “…… কী?” | প্রস্বেদন কী? |
| শূন্যস্থান-ধর্মী | “…… হলো ——” | যে পদার্থের নির্দিষ্ট আকার আছে তা —— |
| নেতিবাচক | “কোনটি … নয়?” | কোনটি তরল পদার্থের বৈশিষ্ট্য নয়? |
| শ্রেণিবিন্যাস | “কোনটি … শ্রেণির?” | কোনটি বিরুৎ উদ্ভিদ? |
| তুলনামূলক | “কোনটিতে বেশি/কম …?” | কোনটির ওজন বেশি? |
| কারণ-ফল | “… হলে কী হবে?” | বেলুনে ফুঁ দিলে কী হয়? |
| একক/সংখ্যা | “……র একক কী?” | তাপমাত্রার একক কী? |
| চিত্রভিত্তিক | ছবি দেখে শনাক্ত | চিত্রে চিহ্নিত অংশটি কী? |
| উদ্দীপকভিত্তিক | ছোট ঘটনা + প্রশ্ন | “রিমা কাঁচের গ্লাসে পানি রাখল…” |
| ব্যাখ্যাসহ | উত্তর + কারণ | (Satt-এ ব্যাখ্যা আলাদা রাখা হয়) |
| “উপরের সবগুলো” | নির্দিষ্ট কিছু ক্ষেত্রে | — |

### 4.2 শূন্যস্থান পূরণ

Two variants, both used:

- **শব্দবাক্স ছাড়া** — “প্রায় সব উদ্ভিদের মূল, কাণ্ড ও —— থাকে।”
- **শব্দবাক্স সহ** — উপরে ৬–৮টি শব্দ, নিচে সমান সংখ্যক বাক্য (ক–ঙ)।

### 4.3 শুদ্ধ/অশুদ্ধ (সত্য/মিথ্যা)

১০টি বাক্য, প্রতিটির পাশে শুদ্ধ/অশুদ্ধ লেখা। Negative statements are common
(“সব উদ্ভিদেরই ফুল হয়।” → অশুদ্ধ) and are a cheap way to test misconceptions.
The English paper uses the same device as T/F.

### 4.4 বাম-ডান মিলকরণ

Two columns, ৪–৫ items on the left, ৫–৬ on the right (one extra distractor):

- শব্দ ↔ অর্থ / সংজ্ঞা
- অঙ্গ ↔ কাজ
- প্রাণী ↔ আবাসস্থল
- পদার্থ ↔ অবস্থা
- যন্ত্র ↔ শক্তি রূপান্তর

### 4.5 সংক্ষিপ্ত উত্তর

One- or two-sentence answers, but the stem often carries a hidden count:

- “মূলের তিনটি কাজ লেখ।”
- “বিরুৎ উদ্ভিদের তিনটি বৈশিষ্ট্য লেখ।”
- “তিনটি গুল্ম উদ্ভিদের নাম লেখ।”
- “সপুষ্পক ও অপুষ্পক উদ্ভিদের দুটি পার্থক্য লেখ।”
- “কেন?” / “কী বোঝায়?” / “কীভাবে?”

### 4.6 বর্ণনামূলক (সৃজনশীল-ধাঁচ)

Multi-part, usually ২–৪টি উপপ্রশ্ন একসাথে:

- সংজ্ঞা + তালিকা + পার্থক্য
  (“মূল কী? মূলের তিনটি কাজ লেখ। মূল ও কাণ্ডের দুটি পার্থক্য লেখ।”)
- কারণ + ব্যাখ্যা
  (“পাতা ছাড়া উদ্ভিদ বাঁচে না কেন?”)
- চিত্র + লেবেল
  (“একটি পরিচিত উদ্ভিদ আঁকো এবং মূল, কাণ্ড, পাতা চিহ্নিত করো।”)
- ছবি/উদ্দীপক দেখে শ্রেণিবিভাগ
  (“ছবির পদার্থগুলো কঠিন/তরল/বায়বীয়ে ভাগ করো।”)

Note: class 3 does **not** use the class-6+ “উদ্দীপক + ক/খ/গ/ঘ” সৃজনশীল structure
as a formal section; the descriptive questions are plain multi-part prompts.

### 4.7 অন্যান্য ধরন (subject-specific but worth supporting)

- **চিত্র অঙ্কন ও চিহ্নিতকরণ** — science, BGS
- **তালিকা/সারণি পূরণ** — science, math
- **গাণিতিক সমস্যা** — math (একক, যোগ-বিয়োগ-গুণ-ভাগ, জ্যামিতি)
- **সংখ্যা কথায় লেখা / ক্রমবাচক-অঙ্কবাচক** — math, English
- **বাক্য গঠন, বিপরীত শব্দ, সমার্থক শব্দ, যুক্তবর্ণ ভাঙা** — বাংলা
- **বানান শুদ্ধ করা, বিরামচিহ্ন বসানো** — বাংলা
- **Rearrange / punctuation / verb form / matching responses** — English
- **অনুচ্ছেদ/ছোট রচনা** — বাংলা, English, BGS
- **সংক্ষিপ্ত টীকা/পরিচয় লেখ** — BGS, religion

## 6. What this means for প্রশ্নপত্র স্টুডিও

Today the studio only knows four buckets: **MCQ, জ্ঞানমূলক, অনুধাবনমূলক, সৃজনশীল**.
Class 3 needs three extra layouts that cannot be squeezed into those buckets:

1. **শূন্যস্থান** — stem with a blank + single answer (+ optional word bank).
2. **শুদ্ধ/অশুদ্ধ** — statement + boolean.
3. **মিলকরণ** — left list + right list + answer key.

Recommended schema addition (per chapter, per type):

```
fill:    { q, a }                       // শূন্যস্থান
tf:      { q, a: true|false }           // শুদ্ধ/অশুদ্ধ
match:   { left: [...], right: [...] }  // বাম-ডান
short:   { q, a }                       // সংক্ষিপ্ত (existing জ্ঞানমূলক can hold this)
descriptive: { q, parts: [...] }        // বর্ণনামূলক (existing সৃজনশীল can hold this)
mcq:     { q, options[4], a }           // existing
```

UI impact:

- Setup page gains three optional type checkboxes/count boxes
  (শূন্যস্থান, শুদ্ধ/অশুদ্ধ, মিলকরণ) — only shown for classes that have them.
- Paper view needs renderers for blanks, T/F rows and two-column match tables.
- The existing “delete one → auto-replace same type” rule extends naturally to the
  new types.

Suggested per-chapter target for Class 3 science (১১ chapters):

| Type | Per chapter | Total |
|---|---|---|
| MCQ | ৩০ | ৩৩০ |
| শূন্যস্থান | ১০ | ১১০ |
| শুদ্ধ/অশুদ্ধ | ১০ | ১১০ |
| মিলকরণ | ৪ সেট | ৪৪ |
| সংক্ষিপ্ত | ১০ | ১১০ |
| বর্ণনামূলক | ৪ | ৪৪ |
| **Total** | | **~৭৪৮** |

That is deliberately close to Satt's ৩৩০ MCQ for the subject, so the app is
competitive without copying a single item.

## 7. Rules kept from the existing project

- NCTB textbook is the only factual source; Satt/Courstika supply *shape*, not text.
- No item is reused verbatim; each stem is rewritten around a textbook fact.
- Global dedupe (normalised stem + n-gram similarity) applies to every new type.
- Everything must render in one offline HTML file, Bengali shaping intact.
